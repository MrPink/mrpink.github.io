# Personal Tech Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A Hugo + PaperMod blog at `https://mrpink-vulncheck.github.io/`, deployed by GitHub Actions on push to `main`.

**Architecture:** Hugo site configured in `hugo.toml`, with the PaperMod theme pulled in as a Hugo module pinned in `go.mod`. Mermaid is wired in through a render hook plus a partial that loads Mermaid only on pages that contain a diagram. A Pages workflow builds the site with a pinned Hugo extended version.

**Tech Stack:** Hugo extended 0.170.1, PaperMod v8.0 (Go module), Mermaid 12.2.0 (jsDelivr ESM), GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-19-tech-blog-design.md`

## Global Constraints
- `baseURL = "https://mrpink-vulncheck.github.io/"` is the only account-specific value.
- No analytics, trackers, comments or third-party scripts except Mermaid, which loads only on pages that contain a diagram.
- No VulnCheck branding.
- Pin every version: Hugo 0.170.1, PaperMod v8.0, Mermaid 12.2.0, and Actions by major version (checkout@v6, setup-go@v6, configure-pages@v5, upload-pages-artifact@v5, deploy-pages@v5).

## Review Focus
1. A post with `draft: true` must not appear in the production build. Test: build, then check that `public/` doesn't contain the draft's slug.
2. A post without a Mermaid diagram must not load Mermaid. Test: grep the about page HTML for `mermaid`; expect no match.
3. `public/index.xml` (RSS) must list the sample post. Test: grep for its title.
4. The build must succeed with `--panicOnWarning` so broken refs or template warnings fail CI.
5. Social cards: post HTML must include an `og:title` meta tag.
